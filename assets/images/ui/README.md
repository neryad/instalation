# Assets de Interfaz (UI)

Imágenes para mejorar la interfaz de usuario del juego.

## Archivos esperados

- `grid_background.png` - Fondo de grid mejorado (1024x1024)
- `danger_overlay.png` - Overlay de peligro para cordura < 30 (1024x1024)
- `critical_overlay.png` - Overlay de cordura crítica < 15 (1024x1024)
- `entity_icon.png` - Icono de la IA/entidad para el mapa (64x64)
- `splash_screen.png` - Splash screen mejorado (1080x1920)

## Especificaciones
- **Overlays:** PNG con transparencia
- **Iconos:** 64x64 PNG
- **Splash:** 1080x1920 PNG, formato portrait
