# Assets Promocionales

Imágenes para marketing y tiendas de aplicaciones.

## Archivos esperados

- `app_icon.png` - Icono de la app (1024x1024)
- `screenshot_game.png` - Screenshot pantalla de juego (1080x1920)
- `screenshot_horror.png` - Screenshot momento de terror (1080x1920)
- `screenshot_map.png` - Screenshot del mapa (1080x1920)
- `banner_horizontal.png` - Banner promocional (1920x600)
- `video_thumbnail.png` - Thumbnail para trailer (1280x720)

## Especificaciones
- **Icono:** 1024x1024 PNG, sin texto
- **Screenshots:** 1080x1920 PNG, formato portrait
- **Banner:** 1920x600 PNG
- **Thumbnail:** 1280x720 PNG
