# Texturas 3D para Raycaster

Texturas tileables (seamless) para el motor 3D del juego.

## Archivos esperados

- `wall_type1.png` - Paredes estándar (verde industrial)
- `wall_type2.png` - Paredes de advertencia (marrón oxidado)
- `floor.png` - Suelo industrial
- `ceiling.png` - Techo con tuberías

## Especificaciones
- **Resolución:** 256x256 PNG
- **Tileable:** Sí, sin bordes visibles al repetir
- **Estilo:** Dark sci-fi, instalaciones subterráneas
